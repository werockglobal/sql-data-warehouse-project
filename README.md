# Data Warehouse and Analytics Project
This repository contains the comprehensive materials for a SQL Server data warehouse project, including source files, SQL scripts, documentation, and data quality assessments.
The project focuses on the integration of raw data from two systems—a Customer Relationship Management (CRM) system and an Enterprise Resource Planning (ERP) system—into a centralised SQL Server data warehouse. The data is meticulously cleaned, standardised, and prepared to facilitate analytical queries and reporting.
For those who are new to the project, we kindly invite you to review the setup guide located in the "00_setup" folder. This guide offers detailed instructions on installing and configuring SQL Server and creating the project database on either Windows or Mac operating systems. Additionally, it provides solutions for addressing common setup challenges.

## Project Requirements
### 1. Building the Data Warehouse (Data Engineering)

### Objective
Develop a modern SQL Server data warehouse that consolidates sales data and enables analytical reporting and informed business decisions.

### Specifications
  - Data Sources: Import CSV files from two source systems: ERP and CRM.
  - Data Quality: Identify and resolve data-quality issues before analysis.
  - Integration: Combine both source systems into a consistent, user-friendly data model for analytical queries.
  - Scope: Work with the latest available dataset. Historical tracking and historization are not required for this project.
  - Documentation: Document the data model clearly for business stakeholders and analytics teams.

## 2. BI: Analytics and Reporting (Data Analysis)

### Objective
Develop SQL-based analytics that provide insights into:
  - Customer Behaviour
  - Product Performance
  - Sales Trends
These analyses should help stakeholders monitor key business metrics and make informed decisions.
